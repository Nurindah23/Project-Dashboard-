# Order Store Dashboard (E-Commerce)

An interactive Tableau dashboard that analyzes 10,000+ order records, focusing on order trends, product demand, and shipping performance.

## Problem
It was difficult to see how many orders shipped late and which ship modes or products were affected, across 10,000+ records.

## Solution
I cleaned and prepared the data in Python, then built a Tableau dashboard that breaks down shipping time by days, ship mode, and year, making delays easy to spot.

## Key Features
- Orders by year and month
- Orders by product sub-category and year
- Orders shipped later than 3 days after the order date
- Orders by ship mode and year
- Delivery coverage map
- Filters for year of ship date and category

## Tools
- **Python:** data cleaning and preparation
- **VS Code:** code editor
- **Tableau:** data visualization and dashboard

## Workflow
Raw CSV Data → Data Cleaning & Preparation (Python) → Build Visualizations (Tableau Worksheets) → Combine into Dashboard + Add Filters → Tableau Dashboard
