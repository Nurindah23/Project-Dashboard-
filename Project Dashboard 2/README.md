# Sales Performance Dashboard (Retail Industry)

An interactive Power BI dashboard that compares actual sales against budget from 2019 to 2021, built from 1,000+ records cleaned in MySQL.

## Problem
Without a clear comparison between actual sales and budget, it was hard to know whether sales targets were being met each month.

## Solution
I cleaned the data in MySQL and built a three-page Power BI report that tracks sales vs budget by month, product, and customer, with slicers for year, month, city, category, and product.

## Tools
- **MySQL:** data storage, cleaning, and transformation
- **Power BI:** data modeling, visualization, and slicers

## Workflow
Raw CSV Data → Store in SQL Database → Data Cleaning & Transformation (SQL) → Import into Power BI → Build Visualizations + Slicers → Power BI Dashboard
