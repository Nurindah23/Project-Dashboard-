# Performance Business Regional (Telecommunications Industry)

A monthly performance report that turns 200,000+ raw records from the OSS system into a clear view of target vs actual results, built in Excel and presented in PowerPoint.

> This project is based on a real report I created during my internship at PT Trans Indonesia Superkoridor, in the Business Performance division.

## Business Problem
Performance data was stored in the OSS system in raw form, making it hard to compare targets against actual results and track monthly and yearly growth.

## Solution
I extracted and cleaned the data in Excel, summarized it with pivot tables, and presented it in a PowerPoint report that shows achievement, MoM, and YoY trends at a glance.

## Key Insights Delivered
- Target vs actual revenue, with achievement percentage
- Revenue trends with month-over-month (MoM) and year-over-year (YoY) growth
- Revenue performance for the B2C segment
- Sales performance against target
- Active customers against target
- Sales, churn, NAL, and freeze movements by month

## Tools & Skills
- **Excel:** data cleaning, processing, and pivot tables
- **PowerPoint:** charts, data visualization, and report design

## Workflow
OSS System (Data Source) → Extract Raw Data → Data Cleaning & Processing (Excel) → Summarize with Pivot Tables (Target vs Actual, MoM, YoY) → Build Charts & Visualizations (PowerPoint) → Performance Report
