# Report Analysis Dashboard (Supplies)

An interactive Looker Studio dashboard that turns 9,000+ raw order records into clear insights on order volume, customer segments, regions, and shipping preferences.

## Business Problem
Stakeholders needed a quick overview of order volume and shipping preferences, but the data was spread across 9,000+ rows.

## Solution
I cleaned the data in Google Sheets and built an interactive Looker Studio dashboard that shows order volume by region, category, segment, and city, with ship mode filters to compare shipping preferences.

## Key Insights Delivered
- Order volume by region, category, segment, and city
- Yearly and monthly order trends
- Top states and customers by quantity
- Shipping preferences across ship modes
- Summary metrics: total orders, customers, states, and segments

## Tools & Skills
- **Google Sheets:** data storage, cleaning, and preparation
- **Looker Studio:** data visualization, dashboard design, and interactive filters

## Workflow
Raw Data (Google Sheets) → Data Cleaning & Preparation (Google Sheets) → Connect Data to Looker Studio → Build Visualizations + Add Filters → Looker Studio Dashboard
